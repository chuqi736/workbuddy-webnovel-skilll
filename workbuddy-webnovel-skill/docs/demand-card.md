# Skill 需求定义卡
### 1. Skill 名称
男频网文题材调研与创作规划助手

### 2. 目标用户
以学生为主的新手网文作者，开新书时缺乏市场热度判断能力，希望自定义对标成熟网文叙事风格，需要成套、可直接落地的网文题材、设定及大纲方案，适配番茄、起点、纵横等主流男频创作平台。

### 3. 对应赛题类别
智能生成与创作 > 全场景内容智能创作

### 4. 对应覆盖赛题
覆盖全场景内容智能创作赛题，实现网文创作全链路赋能：热门题材市场调研、用户创作偏好匹配、自定义叙事风格校准、世界观与角色设定搭建、全书结构化大纲生成。

### 5. 关键词和价值点
关键词：男频网文、热门题材调研、自定义叙事风格适配、网文设定生成、全书大纲规划、轻量化交互创作
价值点：依托主流平台实时热度数据，解决新手作者选题迷茫；支持自定义复刻成熟网文叙事风格与设定逻辑；极简交互即可输出成套可落地创作方案，规避空泛创作建议；设定逻辑自洽、大纲节奏适配市场主流，大幅降低新书创作门槛。

### 6. 真实使用场景
学生作者想要创作都市异能网文，偏好现实叠加超凡暗面的叙事框架，不清楚当下市场热门细分题材，不会搭建独特的规则型力量体系和渐进式世界观。通过本技能输入创作需求后，技能自动检索当下男频热门题材趋势，结合用户偏好与选定叙事风格，筛选适配题材方向，完成双层世界观架构、规则化异能体系、成长型主角人设搭建，最终输出单元事件驱动的结构化全书大纲，作者可直接基于成果开展正文创作。

### 7. 用户输入
用户自由文本输入创作需求，包含：意向题材、目标创作平台、文风偏好、主角类型倾向、创意雏形、想要匹配的叙事风格；技能自动检索番茄、起点、纵横男频实时榜单与题材热度趋势数据。

### 8. Skill 输出
1. 热门题材推荐报告（2-3个适配方向，含市场热度、竞争难度、差异化切入点、推荐指数）；
2. 完整世界观架构（双层现实+超凡世界结构、世界规则、核心场景、势力分布）；
3. 特色力量体系（规则驱动型设定，无传统刻板等级）；
4. 全套人物档案（成长型主角、核心配角、反派人设，含性格、动机、成长弧线）；
5. 核心剧情矛盾（主线冲突、单元支线矛盾、情感线铺垫）；
6. 全书分卷大纲+精细章节标题（小地图到大世界渐进式展开，事件驱动叙事）。

### 9. 标准工作流程
Step1 热度检索：自动抓取主流男频平台实时热门题材、流派趋势数据；
Step2 轻量化交互：通过6个核心问题锁定用户创作偏好、平台、叙事风格、题材意向；
Step3 风格校准：根据用户需求确立叙事、设定、节奏适配方案；
Step4 题材筛选：结合市场热度+用户偏好，输出2-3个最优创作方向并附市场分析；
Step5 方向确认：等待用户选定最终创作题材；
Step6 体系搭建：适配选定叙事风格，生成自洽的世界观、力量体系、人物设定；
Step7 大纲生成：按照渐进式叙事逻辑，输出分卷分层、事件驱动的全书大纲；
Step8 成果整合：输出结构化、可直接复用的全套网文创作方案。

### 10. 触发词
帮我起个网文设定、网文开新书选什么题材、男频现在什么题材火、帮我写个网文大纲、网文设定生成、给我一个都市异能设定、网文前期规划、帮我规划一本小说、模仿爆款网文风格写小说、按照指定风格制作小说大纲

### 11. 结果验收标准
1. 市场数据真实有效，不编造平台榜单、题材热度数据；
2. 叙事风格适配精准，满足双层世界观、规则型力量体系、单元叙事等自定义创作需求；
3. 设定逻辑完全自洽，无世界观、力量体系冲突漏洞；
4. 大纲节奏合理，渐进式展开、事件驱动剧情，可直接落地创作；
5. 交互简洁高效，采访提问不超过 6 个，不冗余追问；
6. 输出成果完整成套，覆盖题材、设定、大纲全维度，具备实际创作价值。

### 12. 不应该做什么
1. 严禁编造平台热度数据、榜单排名、网文行业相关虚假信息；
2. 不脱离用户偏好强行生成题材与设定，不盲目套用固定模板；
3. 不代写小说正文内容，只做前期规划；
4. 不直接抄袭现有网文作品的设定、剧情与世界观；
5. 不对小说流量、热度、收益做绝对化承诺；
6. 不跳过用户确认步骤直接生成最终成套方案。
