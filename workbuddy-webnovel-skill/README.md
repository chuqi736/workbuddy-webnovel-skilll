# WorkBuddy Skill 开发实战：男频网文题材调研与创作规划助手
> 项目背景：面向讯飞AI开发者大赛 Skill赛道开发，基于WorkBuddy Agent Skill规范搭建
> 赛题分类：智能生成与创作 -> 全场景内容智能创作

## 📌 项目简介
本人身份：学生网文创作者
痛点：新书构思阶段重复工作极多
1. 需要手动查找各平台热门网文题材
2. 难以结合市场趋势+个人想法构思设定
3. 缺少标准化流程产出世界观、人设、全书大纲
4. 想要便捷对标同类爆款叙事风格，打造差异化小说设定

目标：开发标准化WorkBuddy Skill，实现「题材市场调研→偏好交互采集→风格校准→设定生成→分卷大纲输出」一体化辅助。

## 🎯 开发全流程复盘
### 阶段1：需求挖掘（访谈调研）
遵循结构化访谈三轮提问，锁定真实业务场景
1. 身份：学生，业余写网文
2. 重复耗时工作：新书前期题材调研、世界观设定、大纲撰写
3. 交付产物：题材方向、完整设定文档、分卷小说大纲

确定归属赛道：智能生成与创作 - 全场景内容智能创作

### 阶段2：方案收敛 & 输出需求定义卡
两个候选方向对比：
1. 纯题材趋势分析助手（仅数据分析）
2. 网文题材调研+设定大纲创作助手【最终选定】
选择理由：链路更长、落地价值更高，区分度更强，符合大赛创作赛道要求。

输出正式《Skill需求定义卡》，明确：
技能名称、目标用户、输入输出、触发词、工作流程、验收标准、禁止行为。

### 阶段3：编写SKILL.md
严格遵守Agent Skill规范：
- 文件头部YAML frontmatter（name + description）
- description强制三段式：核心能力；适用场景；触发词
- 约束边界清晰，避免功能泛化
- 新增特色模块：支持自定义对标网文风格，适配不同叙事框架

### 阶段4：自检优化
自检清单：
- ✅ name命名具象化，拒绝“万能写作助手”泛名称
- ✅ description三段结构完整
- ✅ 触发词≥6条，覆盖口语+书面指令
- ✅ 明确能力边界，区分【辅助规划】和【代写正文】
- ✅ 禁止编造榜单、热度数据，添加内容约束

迭代优化点：
新增风格校准流程，支持双层世界观、规则型力量体系、事件驱动大纲生成逻辑。

### 阶段5：测试验证
构建模拟测试用例：
> 用户需求：都市异能，偏好现代都市隐藏超凡世界观，目标平台番茄，主角为高三学生，觉醒情绪异能，想要悬疑+轻松日常文风，拒绝无脑升级流。
验证目标：题材推荐、世界观、力量体系、人物、大纲能否完整、自洽输出。
